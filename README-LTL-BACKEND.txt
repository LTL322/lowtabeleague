LTL — ОБЩАЯ БАЗА И REALTIME BACKEND

1. Установите Node.js 18+.
2. Положите рядом:
   - index (1).html
   - server.js
   - package.json
3. Запустите:
   npm start
4. Откройте:
   http://localhost:8787/

Что сделано:
- общая серверная база nexus_* для пользователей, ролей, команд, матчей, турниров, сеток, KDA, банов, пиков и остальных данных сайта;
- изменения администратора/главы отправляются на сервер и мгновенно приходят всем открытым клиентам через SSE;
- регистрация нового аккаунта попадает в общую базу и сразу становится видна главе;
- общий online считает все открытые вкладки сайта, включая гостей без аккаунта;
- редактирование карты обновляет только текущую карту и не затирает KDA/данные других карт;
- добавлены отдельные поля «Пики» для обеих команд;
- существующий localStorage остаётся локальным кэшем/резервом, поэтому сайт продолжает работать при временном отсутствии backend;
- исходные функции сайта не удалены.

Первый запуск автоматически переносит существующие nexus_* данные из localStorage клиента на сервер. Если на сервере уже есть данные, серверные значения имеют приоритет, а локальные ключи, которых на сервере ещё нет, также загружаются на сервер — данные не удаляются из-за отсутствующего ключа.

Для публикации в интернете запустите server.js на VPS/Render/Railway/другом Node-хостинге и укажите в HTML перед основным скриптом:
window.LTL_BACKEND_URL = 'https://ВАШ-ДОМЕН';
